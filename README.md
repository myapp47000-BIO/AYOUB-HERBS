## ✨ الميزات التقنية

- **PWA كامل**: قابل للتثبيت على الهاتف والحاسب، يعمل **بدون إنترنت** عبر Service Worker
- **بحث فوري ذكي**: يبحث في كل المحتوى مع تطبيع النص العربي (همزات، تشكيل، تاء مربوطة)
- **مفضلة**: حفظ أي عشبة/خلطة/مرض/حمية/فيديو في المفضلة (localStorage)
- **فهرس الفيديوهات**: 115 فيديو من قناة الخبير مع تصنيف بالموضوع ووسوم وبحث فوري في العناوين، ونافذة فيديو بمشغل يوتيوب وربط مباشر بالعشبة المرتبطة
- **ربط المحتوى بالفيديو**: كل عشبة جديدة تعرض فيديوها الأصلي، وكل حالة مرضية تعرض فيديوهات ذات صلة
- **دليل الأعراض**: اختر عارضاً أو أكثر (إمساك، حصى كلى، صدفية، قولون...) واعرف الحالات المطابقة مرتبة حسب عدد الأعراض
- **حاسبة BMI** و**حاسبة الماء اليومي** تعملان بدون إنترنت
- **برامج العلاج**: تتبّع الوصفات ذات المدة (14 يوماً لتنظيف القولون، شهر للقسط الهندي) مع شريط تقدم ويوم بيوم
- **قائمة العطار**: أضف مكونات أي خلطة بضغطة أو يدوياً، وحدّد المشترى
- **نسخ احتياطي**: تصدير/استيراد المفضلة والبرامج والقائمة والأعراض في ملف JSON
- **مظهر ليلي/نهاري** مع تلوين شريط النظام
- **مشاركة وطباعة** الوصفات
- **وصفة اليوم**: تتغير يومياً
- **عدّادات متحركة** وأرقام إحصائية
- أيقونات Maskable + اختصارات ثابتة (Manifest Shortcuts)
- تصميم أخضر عطاري متجاوب مع دعم RTL كامل وخطوط Cairo/Amiri

## 🚀 التشغيل

### محلياً (للاختبار)
يفضل تشغيل خادم محلي (Service Worker لا يعمل من `file://`):

```powershell
# بأي خادم ثابت، مثلاً عبر بايثون:
python -m http.server 8080 --directory "ayoub-herbs-pwa"
```

ثم افتح: `http://localhost:8080`

### النشر
ارفع المجلد كما هو إلى أي استضافة ثابتة (GitHub Pages / Netlify / Vercel / Hostinger...) — الملفات جاهزة للنشر مباشرة.

## 📁 هيكل المشروع

```
ayoub-herbs-pwa/
├── index.html              # هيكل التطبيق (SPA)
├── manifest.json           # بيان PWA (تثبيت + اختصارات)
├── sw.js                   # عامل الخدمة (عمل بدون إنترنت)
├── css/
│   └── styles.css           # التصميم الكامل (نهاري/ليلي)
├── js/
│   ├── data-core.js         # بيانات القناة والنصائح وفوائد الطب البديل
│   ├── data-herbs.js        # الأعشاب
│   ├── data-mixtures.js     # الخلطات العلاجية
│   ├── data-diseases.js     # الأمراض والحميات
│   ├── data-tools.js        # دليل الأعراض
│   ├── data-videos.js       # فهرس فيديوهات القناة (115 فيديو)
│   └── app.js               # منطق التطبيق (توجيه/بحث/مفضلة/أدوات/نوافذ)
├── icons/                  # أيقونات PWA (مولدة بـ GDI+)
└── tools/gen-icons.ps1      # سكربت توليد الأيقونات
```

## ⚕️ إخلاء مسؤولية

هذا التطبيق **توثيق تعليمي** لمحتوى عام منشور في القناة، وليس وصفة طبية.
الأعشاب تتفاعل مع الأدوية — استشر طبيبك قبل الجمع بينها، والحالات المزمنة
(سكري، ضغط، كبد، حمل) تحتاج إشرافاً طبياً إلزامياً.
